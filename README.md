# OBRM

This repository contains the implementation of OBRM for privacy-preserving approximate nearest neighbor search.

## Getting Started

### OBRM base Compiling and Running

Compiling:
Cmake
Make

Running:
python3 OBRM/run_main.py --scheme base

### OBRM optimized Compiling and Running

Compiling:
Make

Running:
python3 OBRM/run_main.py --scheme optimized
